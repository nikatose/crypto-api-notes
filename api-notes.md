# Crypto API Notes

A small collection of notes about cryptocurrency APIs.

## What is an API?

An API allows one application to request data from another application.

For example, a cryptocurrency API can provide:

- current prices
- historical prices
- trading volume
- market capitalization
- exchange information

## Example

A simple API request might return data like:

```json
{
  "symbol": "BTC",
  "price": 95200
}
